# goosewin-nvim

Personal Neovim configuration based on LazyVim.

## What this is

- Daily driver setup with a curated plugin set
- Opinionated defaults for editing, navigation, and search
- Built on top of LazyVim's base configuration

## Install

```bash
git clone https://github.com/goosewin/goosewin-nvim.git ~/.config/nvim
```

Open Neovim and let LazyVim bootstrap plugins on first launch.

## Update

```bash
cd ~/.config/nvim
git pull
```

Then run `:Lazy sync` inside Neovim.

## Notes

Refer to the LazyVim docs for base behavior and defaults:
https://lazyvim.github.io/installation
